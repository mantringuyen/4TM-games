# 4TM Games — Shared Resources

This directory is reserved for cross-game specifications and assets across the 4TM Games suite.

## Planned Scope
- **Branding:** Official 4TM logos, color palette tokens, unified typography specs.
- **Audio Assets:** Shared audio cues (4TM startup chime, standard UI clicks).
- **Specs & Protocols:** Specification documentation for future `4tm-game-sdk` (bridge between web showcase and game runtimes).
